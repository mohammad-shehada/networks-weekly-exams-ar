# امتحانات الشبكات الأسبوعية

موقع مستقل لمادة Special Topics in Computer Networks (1601204).

18 نموذجًا أسبوعيًا، كل نموذج40 علامة:15 اختيار و5 صح/خطأ و10 فراغات وحالتان بمجموع10.
الأسئلة باللغة الإنجليزية، والواجهة والترجمة والشرح باللغة العربية.

الأمثلة والقيم الحسابية من المحاضرات الخمس المرفقة فقط. الحسابات في الأسابيع3 و4 و5؛ الأسبوعان1 و2 مفاهيم وتصميم.
النماذج تستخدم نفس مفاهيم المادة بأنواع مختلفة من الأسئلة، وليست576 معلومة فريدة.

شرح المحاضرات كامل بمستويين، يغطي221 صفحة في109 مقاطع، مع النص الأصلي والمراجع وأسئلة مرتبطة. تمت مراجعة270 مفهومًا و30 نتيجة حسابية من أمثلة المادة.

التصحيح الموضوعي تلقائي من30، والحالات لها نموذج وسلّم تقييم ذاتي من10.
المظهر فاتح/داكن/تلقائي، والمحفوظات والمسودات محلية على المتصفح.
يمكن طباعة ورقة جامعية فارغة بدون الحلول أوالترجمة أوإجابات المحاولة.

هذا توزيع ثابت جاهز لـGitHub Pages من جذر المستودع. افتح index.html مباشرة أو استضف الملفات كما هي.
ملفات PDF المرفقة نسخ أصلية بدون تعديل، وروابط الحلول تشير إلى صفحة الملف.

نماذج تدريبية وليست أوراق امتحان رسمية، ولا تتضمن ادعاء مطابقة أسلوب صياغة الدكتورة دون ورقة سابقة.
